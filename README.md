# Dmart-Sales-Analysis-Powerbi
DMart sales data analysis project using Power BI, SQL, and Excel. Includes data cleaning, transformation, and interactive dashboards to analyze sales, profit, and regional performance, helping generate clear business insights and support data-driven decisions.
🛒 Dmart Sales Analysis Dashboard -- Power BI Project
📌 Project Overview
This project focuses on analyzing Dmart retail sales data using Power BI
to generate business insights and support data-driven decision making.
An interactive dashboard was built to track sales performance, profit
trends, product insights, and regional performance.
# Dataset Information

This project uses a retail sales dataset representing transactional performance across multiple regions and product segments. The dataset contains over 50,000 records capturing order activity, revenue contribution, profitability trends, and product-level performance.

The data was pre-processed and prepared within Power BI using data cleaning and transformation techniques to ensure accuracy, consistency, and analytical readiness. It supports the creation of interactive dashboards focused on sales performance, category insights, regional analysis, and business decision support.
